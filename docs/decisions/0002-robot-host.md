# 0002. 팔과 카메라는 Jetson에 연결한다

- 날짜: 2026-11-16
- 결정: SO-101 팔 2대와 카메라 2대는 조립·캘리브레이션, 수집, 실행, 평가 전 과정에서 Jetson Orin Nano Super에 연결한다. 데스크톱(WSL2 Ubuntu 24.04)은 개발, 테스트, 분석에 쓴다.

## 근거

1. 수집과 실행이 같은 장비, 같은 카메라 입력 경로에서 이뤄진다. 비교 기준 논문(arXiv 2608.03938)에서 제어 주기를 정한 것은 가속기가 아니라 USB 카메라 캡처 속도였다.
2. Jetson Orin Nano에 팔 2대와 카메라 2대를 연결해 640×480, 30fps로 기록하는 구성이 Waveshare의 SO-ARM100/101 문서에 있다.
3. 데스크톱에 USB 장치를 연결하지 않으므로 듀얼부팅 설치가 필요 없다.

## 조건

- 팔은 Jetson 설치(J)가 끝난 뒤에 받는다. J에서 조작·기록에 필요한 것(SO-101 드라이버, 카메라 캡처, 영상 인코딩)을 팔 없이 확인한다.
- 기록 fps는 D2에 Jetson에서 측정한 제어 주기로 확정한다(목표 30fps).
- Jetson에서 수집이 되지 않으면 데스크톱에 Ubuntu를 듀얼부팅으로 설치해 수집한다(Seeed 문서가 권장하는 방식).
